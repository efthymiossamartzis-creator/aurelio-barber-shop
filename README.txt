Fade — Free Bootstrap 5 Barbershop & Men's Grooming Template by uiCookies
https://uicookies.com/

Fade is a free, bold two-page website template for barbershops, grooming
studios and men's salons, built on Bootstrap 5 with a distinctive dark-charcoal
and brass identity. It includes a home page (hero, services & pricing, barbers,
a filterable cuts gallery with lightbox, an online booking form, a grooming
shop, a loyalty band, hours, and testimonials) plus an About page (shop story,
count-up stats, the crew and a gallery). Every interaction — the mobile menu,
sticky navbar, gallery filter, lightbox, booking validation, add-to-bag and
sliders — is written in plain vanilla JavaScript with no jQuery and no plugin
dependencies. Content stays visible with JavaScript off, and all motion respects
prefers-reduced-motion. Free for personal and commercial use under the uiCookies
license (attribution appreciated). The booking form is front-end only — point
the <form> at your backend or a scheduling service to make it live. Replace the
demo photos with your own optimized images before going live.

WHAT'S INSIDE
  index.html        Home page
  about.html        Shop story, barbers and gallery
  css/vendor/       Bootstrap 5 (minified)
  css/style.css     Template design layer (custom properties, all styling)
  js/vendor/        Bootstrap 5 bundle (includes Popper)
  js/main.js        Template behavior — vanilla JavaScript, no jQuery
  img/              Demo images
